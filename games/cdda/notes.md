# Cataclysm: Dark Days Ahead 지식 노트

## 실행 환경

- 원격 샌드박스(디스플레이 없음)에 소스에서 직접 빌드한 curses 전용 빌드 사용.
  `scripts/setup-cdda.sh`가 클론+빌드(`TILES=0 SOUND=0 LOCALIZE=0`)를 수행한다.
- `qa/runner/play_cdda.py`가 pexpect로 pty를 열고 pyte로 화면을 재구성하는
  드라이버. Angband의 `-mtest` 같은 전용 테스트 프론트엔드가 없어서 실제
  ncurses 출력을 그대로 파싱해야 한다.

## 확인된 규칙/조작법

- 메인 메뉴/서브메뉴 커서 이동: 방향키(ESC [ A/B/C/D)가 아니라 **vi 키
  (`h`/`j`/`k`/`l`)** 가 동작한다. ncurses가 `keypad()`+`smkx`로 애플리케이션
  커서 모드를 켜기 때문에 일반 CSI 방향키 시퀀스가 인식되지 않는 것으로 보임
  (SS3 `ESC O A/B/C/D` 시퀀스는 아직 미검증).
- 메인 메뉴 → New Game → "Play Now! (Default Scenario)" 로 캐릭터 생성
  단계를 건너뛰고 무작위 직업/특성으로 바로 시작할 수 있다.
- 첫 실행 시 "Loading files" → "Finalizing Crafting recipes" →
  "Verifying Skills" 등 데이터 초기화 단계가 순차로 뜨고, 완료까지 새 world
  기준으로 20초 이상 걸린다.
- 기본 시작 위치는 "evac shelter"(대피소) 내부, 목요일 5월 20일 오전 8시.

## 확인된 규칙/조작법 (계속)

- 실제 게임(맵) 화면에서도 이동은 `hjkl`(및 대각선 `yubn`으로 추정, 미검증)로
  동작한다. 한 번 누를 때마다 게임 내 시간이 약 1초 진행된다(Time 필드로 확인).
- `i` = 인벤토리 열기. 화면에 "Items worn / Tools / Manuals / Currency" 등
  카테고리별로 뜬다. `esc`로 닫힌다.
- `esc`는 대부분의 서브메뉴/팝업에서 "취소하고 이전 화면으로" 동작한다.
  단, **메인 메뉴에서 `esc`는 "Really quit? (Case Sensitive) [Y]es [N]o"**
  종료 확인창을 띄운다 — 종료가 아니라 그냥 뒤로가기를 기대하면 안 된다.
- 닫힌 문(`+`) 방향으로 이동하면 자동으로 열리며 심볼이 `'`(열린 문)로
  바뀐다(문을 여는 별도 명령 없이 이동만으로 처리됨).
- 캐릭터/월드가 생성돼도 **저장 파일은 즉시 생기지 않는다.** 실제로
  캐릭터를 만들고 1~3턴 움직인 뒤 강제 종료(컨테이너 재시작으로 프로세스
  kill)했더니, 재시작 후 "Load" 메뉴에서 "Rolinda has no characters to
  load!"가 떴다 — 명시적으로 저장하지 않으면 진행 상황이 사라진다.
- "Play Now! (Default Scenario)"는 매번 새 캐릭터(무작위 이름/직업/특성)를
  같은 world("Rolinda" 등 자동 생성된 world 이름)에 만든다.

## 가설 단계 (아직 검증 중)

- `Q`(shift+q)를 눌러도 즉시 반응이 없었다 — 기본 키바인딩에 "Quit"이
  매핑되어 있지 않거나, 확인창이 뜨는 데 필요한 대기시간이 더 길었을 수
  있다. 저장/종료 명령은 다음 세션에서 `?`(키 도움말) 또는 메인 메뉴의
  다른 경로로 다시 확인할 것.
- 이동 중 맵 화면에 플레이어(`@`)로 보이는 표시가 두 곳에서 동시에 나타난
  적이 있다(하나는 실제 최신 위치, 하나는 문 근처 이전 위치로 추정되는
  자리). pyte 터미널 캡처 쪽 아티팩트인지, 실제로 다른 개체(NPC 등)가
  거기 있는 것인지 아직 구분하지 못했다.

## 모르는 것 / 앞으로 탐색할 것

- 대각선 이동(`yubn`), 조사(`x`/examine), 줍기(`,` 또는 `g`), 제작 메뉴,
  전투, 명시적 저장(Save and Quit) 명령.
- 위에서 언급한 "중복된 @" 표시의 정체.

## 막힌 지점 / 주의사항

- 이 샌드박스는 사용량 한도 등으로 컨테이너가 재시작될 수 있고, 그 경우
  `nohup`으로 띄워둔 CDDA 프로세스(및 세션 드라이버)가 함께 죽는다. 디스크에
  쓴 파일(빌드 산출물, 이 로그 등)은 살아남지만 **저장하지 않은 게임
  진행 상황은 사라진다.** 다음 세션에서 이어 하려면 반드시 게임 내에서
  명시적으로 저장하는 방법부터 확인해야 한다.
